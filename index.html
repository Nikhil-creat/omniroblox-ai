Features

Agent pipeline

Planner defines client/server boundaries, Coder writes typed Luau, Reviewer hunts exploits.

Dynamic model routing

Detects live Groq models at startup and lets you pick fast and heavy roles.

Security audit

Remote injection, client authority, leaks and performance review on every build.

Auto-patch

Paste a stack trace and get the root cause with a fixed block.

UI to Luau

Describe a wireframe and get a scalable ScreenGui hierarchy.

RAG backend

Qdrant with Roblox best practices, Redis session memory, Celery workers.

Architecture

Studio plugin→Nginx→FastAPI + WebSocket→Planner→Coder→Reviewer

FastAPI also talks to Qdrant (RAG), Redis (session memory, broker) and Celery workers. Groq models are detected at boot.
