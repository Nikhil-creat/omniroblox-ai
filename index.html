FAQ

Is it really free?

Yes. It uses your own Groq key on Groq’s free tier. Limits apply, and the app retries once on rate limits.

Is my API key safe?

The key lives only in this tab’s memory and is sent only to api.groq.com. A strict Content-Security-Policy blocks other network calls. Never commit keys to GitHub.

Which models are used?

The site detects what your key can access and picks defaults. You can change fast, heavy and vision roles in the dropdowns.

Can I trust the generated code?

Always test in Studio and run the Audit mode on final code. Never let the client decide currency, damage or prices.

Is this affiliated with Roblox or Groq?

No. It is an independent open-source project.
